# 视频 · GIF 工具箱

Windows 桌面小工具，全部处理在本地完成，无需联网、不上传文件。基于 Electron + FFmpeg 9.0（自带二进制，无需安装）。

## 功能（18 个，5 大类）

### 转换
| 功能 | 说明 |
|---|---|
| 🎞️ 视频转 GIF | 选时间段、帧率、宽度、颜色数；调色板两遍编码，画质好 |
| 🎬 GIF 转视频 | 转 MP4（`yuv420p`，手机可播）或 WebM |
| 🖼️ WebP 动图 | 视频/GIF 转动画 WebP，比 GIF 小 30~50% |
| 📦 格式转换 | MP4 / MKV / WebM 互转，可选分辨率与画质 |

### GIF 编辑
| 功能 | 说明 |
|---|---|
| 🗜️ GIF 压缩 | 降宽/降帧/减色 + 重新调色板，显示节省百分比 |
| 💬 GIF 加文字 | 打字幕、配梗文字（微软雅黑，支持任意中文与特殊字符） |
| 🎯 压缩到目标大小 | 视频（码率法，一遍到位）或 GIF（最多 6 轮迭代），压到 8/25/50/100MB 以内 |

### 剪辑
| 功能 | 说明 |
|---|---|
| ✂️ 视频截取 | 无损模式秒级完成；精确模式重编码帧级对齐 |
| 🔗 视频合并 | 多文件无损拼接（concat demuxer，需同规格） |
| 🔲 画面裁剪 | 预览图上拖框选区，所见即所得 |
| 🔁 旋转 / 翻转 | 90°/180°/镜像，视频与 GIF 都支持 |
| ◀️ 倒放 / 往复 | 倒放，或"正放+倒放"boomerang 循环 |
| ⚡ 变速 | 0.25x ~ 4x，画面 setpts + 音频 atempo 级联，声画同步 |

### 音频
| 功能 | 说明 |
|---|---|
| 🎵 提取音频 | 存为 MP3 / M4A / WAV |
| 🔊 音频调整 | 静音、调音量、淡入淡出（画面不重编码） |
| 🎼 添加背景音乐 | 替换原声或混合，音乐自动循环、音量可调 |

### 工具
| 功能 | 说明 |
|---|---|
| 📸 视频截图 | 单帧截图（PNG/JPG）或按间隔导出帧序列到文件夹 |
| 🖼️ 图片合成视频 | 多张图片（可不同尺寸）合成 GIF 或 MP4，自动黑边居中对齐 |

输出文件默认生成在**源文件同目录**，自动加后缀（如 `xxx_gif.gif`）。

## 使用

- **免安装运行**：双击 `release/视频GIF工具箱-2.0.0-便携版.exe`
- **安装版**：`release/视频GIF工具箱-2.0.0-安装版.exe`（若便携版被杀软误报，用这个）
- **开发模式**：`npm start`

## 开发

```bash
npm install          # 建议配置 ELECTRON_MIRROR 等 npmmirror 镜像
npm start            # 运行
node scripts/smoke-test.js   # 冒烟测试（自动生成素材，32 用例覆盖全部功能）
npm run dist         # 打包便携版 + 安装版到 release/
```

## 代码结构

```
main.js            Electron 主进程：窗口、IPC（文件对话框/首帧提取/批量探测）
ffmpeg.js          核心：ffprobe 探测、ffmpeg 执行（进度解析/取消）、18 个功能的命令构建
preload.js         contextBridge 安全桥接（含 webUtils.getPathForFile 处理拖拽路径）
renderer/          界面（配置驱动生成参数面板；含裁剪画布交互）
bin/               ffmpeg.exe / ffprobe.exe（gyan 9.0.2，打包时经 extraResources 释放）
scripts/           冒烟测试、WebP 渲染校验工具
```

## 技术备注

- **为什么自带 ffmpeg 9.0.2 而不用 ffmpeg-static**：后者内置的 ffmpeg 6.1 存在动画 WebP 编码缺陷（输出文件损坏，Chromium 也无法解码），且 9.0 对 filtergraph 引号解析更严格。项目已针对 9.0 适配：GIF 加文字走 textfile（免疫特殊字符）、图片合成走临时序列（规避 filter 热重配置 bug）。
- 无损截取使用输出端 seek（`-i` 在 `-ss` 前），时长精确；起点若不在关键帧，个别播放器开头可能短暂定格，需要完美开头就用"精确"模式。
- 视频目标大小压缩按 duration 反推码率（含 5% 容器开销余量）；GIF 为迭代降参（宽度/帧率/颜色逐级收紧，最多 6 轮），极复杂的动画可能压不到极小目标，会保留最优一轮的结果。
